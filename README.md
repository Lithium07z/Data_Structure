## 저장소 구성

- 각 주차 아래의 `실습N/src/`: 자료구조 구현과 실행 예제
- `bin/`: 당시 컴파일된 클래스 파일
- 주차별 PNG 이미지와 ZIP 파일: 실습에 함께 보관한 자료
- `1주차 실습/`의 `.project`, `.classpath`, `.settings/`: Eclipse 프로젝트 설정

각 실습은 독립된 프로그램입니다. 여러 폴더에 `Main`, `Node`, `BST`처럼 같은 클래스명이 있으므로 실습 단위로 열고 빌드합니다.

## 실행 방법

JDK와 Java IDE 또는 터미널을 사용합니다. 저장된 1주차 Eclipse 설정은 Java 11 기준입니다.

가장 간단한 예제로, 저장소 루트에서 다음 명령을 실행합니다.

```shell
javac -encoding UTF-8 -d out "1주차 실습/src/HelloWorld.java"
java -cp out HelloWorld
```

출력:

```text
"Hello World!"
```

다른 실습은 해당 `src` 안의 관련 Java 파일을 함께 컴파일하고, `main` 메서드가 있는 클래스를 실행합니다. Eclipse에서는 `.project`가 있는 1주차 폴더를 기존 프로젝트로 가져올 수 있습니다. 나머지는 Java 프로젝트를 만든 뒤 원하는 실습의 `src`만 소스 폴더로 지정합니다.
